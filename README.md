# Food 🍲

Домашний калькулятор блюд.

Идея: хранить калькуляционные карты блюд и автоматически пересчитывать количество ингредиентов под нужное число человек.

## MVP
- категории блюд;
- поиск;
- калькуляционная карта;
- пересчёт ингредиентов;
- быстрый выбор количества порций;
- адаптивный интерфейс;
- GitHub Pages.

## Дальше
- добавление своих блюд;
- редактирование рецептур;
- сохранение рецептов;
- пошаговое приготовление;
- список покупок;
- импорт/экспорт рецептов.
